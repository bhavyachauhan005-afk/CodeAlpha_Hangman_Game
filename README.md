# CodeAlpha Hangman Game

## Description
This is a simple Hangman Game developed in Python as part of the CodeAlpha Python Programming Internship.

## Features
- Random word selection
- Letter guessing
- 6 attempts
- Displays guessed letters
- Win/Lose message

## Technologies Used
- Python 3

## How to Run
1. Download the project.
2. Open terminal in the project folder.
3. Run:
   python hangman.py
